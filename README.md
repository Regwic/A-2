# А в квадрате

Адаптивная страница медиа о бизнесе, людях и идеях. Сохранены композиция, палитра, типографика и абстрактная графика исходного дизайна.

## Локальный просмотр

Нужен Node.js. Установка зависимостей и сборка не требуются.

```sh
npm run dev
```

Открыть `http://127.0.0.1:4173`. Для другого порта: `PORT=4174 npm run dev`.

```sh
npm run check
```

## Устройство

- `index.html` — контент и семантическая разметка.
- `styles.css` — исходный дизайн, мобильная адаптация, состояния и анимации.
- `app.js` — мобильное меню, настройка движения, появления заголовков и блоков, параллакс при прокрутке на телефоне и эффект наклона на компьютере.
- `assets/favicon.svg` — векторная иконка.
- `vercel.json` — статическая публикация без сборки.

Внешние JavaScript-библиотеки не используются. Google Fonts подключены с системными запасными шрифтами. Страница остаётся читаемой без JavaScript; меню и переключатель движения добавляются при его загрузке. Системная настройка уменьшения движения учитывается, выбор пользователя сохраняется локально, прокрутка при выключении анимации остаётся нативной.

## Публикация

Импортировать `Regwic/A-2` в Vercel, выбрать **Other**, корневую папку репозитория и статический вывод `.`. Команды установки и сборки не нужны. Переменные окружения не требуются.

Контактная ссылка: `mailto:bogArs@inbox.ru` из исходного файла. Страница не отправляет формы и не требует сервера приложений.
